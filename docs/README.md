# Документация проекта

Это Telegram-бот на **NestJS** (Node.js фреймворк) с использованием библиотеки **grammY** для общения с Telegram Bot API. Бот умеет конвертировать валюты по тексту сообщения, а также содержит заготовку для второго режима — «Крафт» (пока не реализован).

Архитектура проекта — «гексагональная» (она же «порты и адаптеры», она же чем-то похожа на Clean Architecture). Если вы не сталкивались с этим раньше — не пугайтесь, ниже всё объяснено на пальцах.

## С чего начать чтение

1. [`architecture.md`](./architecture.md) — что такое «порты и адаптеры» и как это устроено именно в этом проекте. **Прочитайте это первым**, иначе структура папок покажется странной.
2. [`modules/core.md`](./modules/core.md) — общие вещи, не привязанные к конкретной функции бота (конфиг, здоровье сервиса, режимы пользователя).
3. [`modules/bot.md`](./modules/bot.md) — ядро бота: приём сообщений от Telegram, меню, запуск.
4. [`modules/currency.md`](./modules/currency.md) — модуль конвертации валют (самая содержательная часть проекта).
5. [`modules/craft.md`](./modules/craft.md) — заглушка второго режима.
6. [`request-flow.md`](./request-flow.md) — сквозной пример: что происходит с момента, когда пользователь написал боту, до момента ответа.
7. `c4-diagram.puml` — диаграмма в формате PlantUML (C4-модель), можно открыть в IntelliJ/WebStorm с плагином PlantUML или на сайте plantuml.com.

## Быстрый старт (как запустить)

```bash
npm install
npm run start:dev   # режим разработки, с автоперезапуском
npm run build && npm run start   # прод-сборка
```

Перед запуском нужен файл `.env` в корне проекта (см. [`architecture.md#конфигурация`](./architecture.md#конфигурация-env)) с как минимум двумя переменными:

- `BOT_TOKEN` — токен Telegram-бота от [@BotFather](https://t.me/BotFather)
- `EXCHANGE_API_KEY` — ключ от сервиса [exchangerate-api.com](https://www.exchangerate-api.com/)

Без них приложение не запустится — это специально (см. `src/core/config.ts`).

## Технологии

| Технология | Зачем нужна |
|---|---|
| [NestJS](https://nestjs.com/) | Каркас приложения: Dependency Injection, модули, декораторы |
| [grammY](https://grammy.dev/) | Библиотека для работы с Telegram Bot API |
| [Fastify](https://fastify.dev/) | HTTP-сервер под капотом Nest (вместо Express) — нужен для health-check и вебхука |
| TypeScript | Язык проекта |
| [Frankfurter API](https://frankfurter.dev/) / [ExchangeRate-API](https://www.exchangerate-api.com/) | Внешние источники курсов валют |

## Карта каталогов

```
src/
├── main.ts                 — точка входа, поднимает Nest-приложение
├── app.module.ts            — корневой модуль, собирает всё вместе
├── core/                    — общая инфраструктура, не специфичная для бота
│   ├── config.ts             — проверка обязательных переменных окружения
│   ├── domain/                — базовые кирпичики домена (DomainException)
│   ├── event-bus/              — шина событий (пока нигде не используется активно)
│   ├── health/                 — HTTP health-check эндпоинты
│   └── user-mode/               — в каком режиме сейчас находится каждый чат
└── modules/
    ├── bot/                  — ядро бота: приём апдейтов, меню, запуск (polling/webhook)
    ├── currency/              — модуль конвертации валют
    └── craft/                 — заготовка второго режима (заглушка)
```

Подробности по каждой папке — в соответствующих файлах документации (см. список выше).
